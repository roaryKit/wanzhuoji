# 独立环境部署与验收（人工操作指南）

本候选没有自动云部署/建库/种子/清理/微信上传脚本，不会修改已有环境。公开前确认项目权属与许可；第三方仅清单/锁、不分发实现的边界见THIRD_PARTY_NOTICES。以下始终在**独立私有副本、独立测试环境**进行。

## 本地配置

- `miniprogram/utils/config.js`是标识配置源；`project.config.json`、`cloudbaserc.json`及七份函数config保存同步值。
- `scripts/configure.js`替换这个私有副本中目标标识的所有部署/测试引用，再更新配置敏感的指纹。已有严格目标/AppID检查不会被删除或改为信任客户端。
- `node scripts/sync-config.js`同步生成配置；`--check`只核对一致性，不联网。
- AppID/环境ID不是密码，但不在公开候选内捆绑任何真实项目标识。不要公开配置后的私有副本。`config/wechat.example.json`与`.env.example`只有占位符。
- Node20+；根项目无第三方开发依赖，`npm ci`只验证根锁与本地工具链，不安装函数SDK。七个函数各自有相同锁定依赖wx-server-sdk@4.0.2，可以在各函数目录`npm ci --ignore-scripts`，或由微信开发者工具云端安装依赖。不要把node_modules提交进仓库。

## 微信/云开发控制台

1. 使用自己的小程序与独立云环境。根据平台要求完成必要认证/能力开通，费用/额度自行在官方后台确认，本候选不自动付费。
2. 创建数据模型文档列出的13集合；数据库规则保持客户端拒绝读写。规则文件是逐集合应用的清单，**不是可直接导入的CLI规范**。索引随实际查询逐项验证。
3. 审查存储规则、上传目录约束和私有链接读取。`config/storage-policy.example.json`是要求清单，不是假装能通用部署的ACL表达式。存储不具备安全条件时先不启用图片，不放宽权限。
4. 导入项目根目录；分别对七个函数“上传并部署：云端安装依赖”。配置声明的文本/媒体安全接口权限必须可用；不要部署任何模拟身份诊断函数。
5. 配置媒体审核回调的HTTPS入口与微信安全模式JSON，服务端环境变量使用自己的`WZJ_CALLBACK_TOKEN`、43字符`WZJ_CALLBACK_AES_KEY`、固定模式`wechat-aes-json`。值必须由微信后台/受控管理员设置，不写入仓库、截图或日志。不提供任何示例真密钥。
6. 核对运行环境/AppID、函数状态、数据库和存储ACL、回调验签。开发者工具/手机报错需按真实错误排查；不能关URL校验、改公开权限或伪造审核来绕过。
7. 安全与功能验证后手动编译、预览/体验。正式发布、提审、体验成员、订阅推送等不是本候选自动进行的事情。

## 验收清单

- 未成年拒绝、年龄未确认、身份/目标环境错误都被门控。
- A/B两个真实授权测试账号：私密记录不互见，公开待审不出广场；点赞重复/取消、评论回复/删除/分页正确。
- 资料真实审核、头像签名URL与到期、匿名文案与行为一致。不能只读取自己头像就宣布跨账号正常。
- B申请→A待审入口→批准/拒绝→成员状态/缩略图→双方新旧消息；自己右他人左，桌主角色不改变方向。
- 满员、每人3桌、重复申请/批准、转让、移除、退出、解散后的读取撤权与缓存清空；不得代真实用户审批。
- 深浅320/390、微信胶囊/安全区、键盘、收缩锚点、固定切换与热tab位置；首次加载单独量化。模拟截图不替代这一步。
- 分享能力依实际认证与平台限制；圆桌图片仍关闭；无微信推送配置/授权时不得声称通知已发送。

发生安全问题先隔离环境，不用清空真实数据库或放开ACL来演示“修好”。

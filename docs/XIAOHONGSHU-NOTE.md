## 可复制正文
最近把一个原生微信小程序整理成可移植的学习源码，记录一次“另一台电脑怎么接着用”的过程。

它有个人记录、酒单、公开内容交流和人工审批的圆桌；圆桌目前只做文字。主题保留暖金深浅配色，公开候选改用自制几何占位图，不带原项目账号、用户记录或演示数据。

跟做顺序👇
① 下载源码，先跑 npm ci --ignore-scripts，再 npm test / npm run check。
② 复制私有部署副本，配置自己的AppID和独立云环境。默认占位配置被拦是正常门控。
③ 建空集合、核对数据库/存储权限，部署七个业务函数，配置自己的审核回调。
④ 从空态开始，用有权使用的两个成年账号验证申请→桌主站内待审→批准/拒绝→聊天→退出撤权。

这次最值得学的不是换皮：申请提交不等于已入桌；热缓存不能绕过成员权限；自己消息靠右、别人靠左应按当前身份，不按管理员身份。

也把限制写清：真实跨账号头像、微信审核、多设备和键盘仍需手机复验；首次加载没证明彻底解决；圆桌图片后续再做。单元测试和模拟截图不等于真机全链通过。
